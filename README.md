# 🏛️ Civic Frontend Prototype: Portal Municipal

Prototipo de interfaz de usuario (UI) responsiva diseñada para modernizar la presencia digital de una municipalidad local (Cholchol, Chile). El enfoque principal de este proyecto es la **Accesibilidad Web (A11y)** y el rendimiento en dispositivos móviles.

## 🚀 Tecnologías Utilizadas

* **HTML5 Semántico:** Uso de etiquetas `<header>`, `<main>`, `<section>`, `<article>` y `<footer>` para estructuración lógica.
* **Accesibilidad (A11y):** Implementación exhaustiva de atributos `aria-label`, `role` y `aria-required` para compatibilidad con lectores de pantalla.
* **Estilos:** Bootstrap 5 (Grid System) + CSS3 nativo.
* **Interactividad:** Vanilla JavaScript (ES6) para validación de formularios en el cliente y manipulación del DOM, sin depender de librerías pesadas.

## 📌 Características

* Renderizado ultrarrápido (Cero dependencias pesadas de JS).
* Diseño *Mobile-First*.
* Formulario de contacto con validación nativa y feedback visual de errores.
* Filtro de búsqueda de trámites en tiempo real.
